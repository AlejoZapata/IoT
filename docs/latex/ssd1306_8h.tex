\doxysubsection{Detailed Description}
API grafica para un display OLED SSD1306 de 128x64 conectado por I2C. 

Las operaciones de dibujo modifican un buffer en RAM. Para mostrar los cambios en el display se debe llamar a \doxylink{ssd1306_8h_ae55a7077a830bfc6ec2eb2b0d479db0d}{ssd1306\+\_\+update()}.
