\doxysubsection{Detailed Description}
Sistema de control para ESP32-\/\+S3 usando ESP-\/\+IDF y Free\+RTOS. 

Este archivo gestiona la lectura de múltiples sensores de temperatura (dos LM35 vía ADC y un DHT11) y el control de 5 relés por medio de comandos enviados por consola serial. \begin{DoxyAuthor}{Author}
