Detailed Description

Implementacion de la comunicacion temporizada con el sensor DHT11.

El protocolo se muestrea mediante espera activa y una seccion critica para reducir variaciones de temporizacion durante la recepcion de los 40 bits.

◆ dht11_init()

esp_err_t dht11_init ( int gpio_pin)

Prepara el GPIO para comunicarse con el sensor DHT11.

Configura el pin como salida con nivel alto y habilita el pull-up interno. Debe llamarse antes de dht11_read().

Parameters
gpio_pinGPIO conectado a la linea de datos del sensor.
Returns
ESP_OK al completar la configuracion.

◆ dht11_read()

esp_err_t dht11_read ( int gpio_pin,
dht11_data_t * out )

Solicita y obtiene una muestra del sensor DHT11.

La funcion bloquea mientras genera la senal de inicio y mide la respuesta. La muestra solo se copia a out si la comunicacion y el checksum son validos.

Parameters
gpio_pinGPIO conectado a la linea de datos del sensor.
[out]outEstructura donde se guardaran temperatura y humedad; no puede ser NULL.
Returns
ESP_OK si la muestra es valida, ESP_ERR_TIMEOUT si no se recibe una transicion esperada, o ESP_ERR_INVALID_CRC si falla el checksum.
